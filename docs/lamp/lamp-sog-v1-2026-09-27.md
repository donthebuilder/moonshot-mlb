# lamp-sog-v1 — LAMP SHOTS board (definition)

Written 2026-09-27 (BATCH-LAMP-V2-MODELS-PLAN, model 1 of 3). The code that
implements this is this document and nothing more. A change to any line
below is a new `model_version`; rows already written keep theirs.

| | |
|---|---|
| **TARGET** | 3 or more shots on goal in the game (boxscore `sog`). Bar 3 is decided (Donovan 09-27): it matches the common 2.5 line. |
| **WINDOW** | One game. |
| **POPULATION** | The dressed skaters (play-by-play `rosterSpots`) once lineups post; before that, the club roster. Goalies are never scored. |
| **LEGS** | Three, each a real feed field: |
| | `shotsPg` — shots per game over his last ~82 NHL games, pooled from this season's and last season's club-stats lines with the same `pooledLegs()` weighting as lamp-goal-v1 (last season fills the window up to 82 games). |
| | `toi` — average time on ice per game: this season's once he has 5+ GP, else last season's (same rule as lamp-goal-v1). |
| | `oppSaPg` — the OPPONENT's shots against per game: the sum of its goalies' `shotsAgainst` (club-stats) over its games played (standings `gamesPlayed`), this season once it has 5+ GP, else last season's. Higher = he faces a team that gives up shots. |
| | Dropped: power-play TOI. The club-stats feed the tick already reads has no PP TOI, and no new call is added for one leg (the plan's rule). |
| **MIN GAMES** | 10 pooled NHL games; fewer = NOT ON THE BOARD, reason printed ("fewer than 10 NHL games on file (N)"). |
| **SCORE** | The mean of the three legs' percentile ranks in the NIGHT's scored population, 0-100 (`percentiles()`, ties share the mean rank). `oppSaPg` is shared by every skater in a game, so it moves a whole game's skaters together against the other games — it never re-orders teammates. |
| **RANK** | Within the game, by score; ties by `shotsPg`. |
| **CALLED** | Top 3 per game. ON THE BOARD = scored, 4th or lower. NOT ON THE BOARD = on the roster, not scored, the reason kept. The words come from the model's output only. |
| **LOCK** | The same 10-minute snapshots as lamp-goal-v1 from T-100 minutes; nothing written at or after puck drop; the last write before puck drop is the lock. |
| **GRADE** | Off the boxscore after the final: `dressed`, `value` = his `sog`, `hit` = value >= 3. Not dressed = VOID (never a miss). The scoring columns are never touched by the grade. |
| **VERSION** | `lamp-sog-v1`, in the primary key (`lamp_prop_log`, market `SOG`). |
| **PRICE** | odds_lines already saves NHL `sog` lines at lock; the record lists which lines the books offered (2.5 mostly) so ROI can be read by price later. The bar stays 3 whatever the line. |
| **TUNING** | None before ~30 graded regular-season nights (the MOONSHOT lesson). The coverage question is measured from night one: of the skaters who reached 3 SOG, how many were on the board. |
