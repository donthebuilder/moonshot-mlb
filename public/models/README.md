Optional glTF models for the 3D parks (lib/stadiumLook.loadModels).
Drop CC0 models from polyhaven.com here, exported as glTF (1k textures):
  pine.glb       ← pine_tree_01
  palm.glb       ← island_tree_01 (or any palm)
  jacaranda.glb  ← jacaranda_tree
Any file that is missing changes nothing; the procedural tree stays.
